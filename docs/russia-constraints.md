# Ограничения для аудитории в России

Документ фиксирует, какие внешние сервисы можно использовать, а какие — нет. Правило по умолчанию: **всё критичное работает офлайн**, сеть — только для необязательных функций.

## Сервисы

| Сервис | Статус | Решение |
|---|---|---|
| Google Play (публикация, оплата) | оплата недоступна из РФ, публикация ограничена | APK + RuStore; Google Play — позже, если появится юрлицо и доступ |
| Firebase (FCM, Analytics, Crashlytics) | доступ нестабилен, консоль требует зарубежный аккаунт | не используем в MVP; уведомления — локальные |
| Google ML Kit | запрещён условиями проекта, плюс зависимость от Google Play Services | не используем |
| Supabase | HTTPS-доступ обычно есть; free tier, зарубежная карта для платных планов | только необязательный бэкап, за feature-флагом |
| Vercel | доступен, но не для медицинских данных | лендинг/админка, не в MVP |
| Cloudflare (Email Routing, Workers) | доступен; нужен свой домен | вариант для почты на следующем этапе |
| GitHub | доступен; CI может работать медленно | исходники и CI |
| Sentry | доступен, но передаёт данные за рубеж | не используем в MVP; локальные логи |
| Stripe / Google Pay / Apple Pay | недоступны | платежей в MVP нет |
| Карты, геолокация | не нужны | не подключаем |

## Правила проектирования

1. **Никаких обязательных сетевых вызовов при старте.** Приложение открывается и работает без интернета.
2. **Никакой телеметрии по умолчанию.** Логи — локально, экспорт — вручную.
3. **Никаких внешних AI-сервисов.** OCR, классификация и извлечение полей — на устройстве.
4. **Сетевые функции — за флагом.** Supabase, почта, синхронизация включаются пользователем отдельно.
5. **Данные не уходят третьим лицам.** Экспорт — только по явному действию пользователя.
6. **Зависимости — с открытой лицензией.** Платные SDK и trial-лицензии не используем.
7. **Сборка не должна требовать Google-аккаунта.** `flutter build apk` и локальный запуск — без Play Services.

## Что это значит для UX

- Онбординг объясняет, что документы хранятся на телефоне.
- Нет экрана «Войдите через Google».
- Бэкап предлагается как опция, а не как условие работы.
- При отсутствии сети приложение не показывает ошибок — просто работает локально.
