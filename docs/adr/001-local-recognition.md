# ADR-001. Локальный контур распознавания

## Контекст

Приложение обрабатывает медицинские документы — специальную категорию персональных данных. Заказчик запретил использовать внешние AI-API, облачные OCR и генеративные LLM. Допустимы только узкие локальные модели под конкретную задачу.

## Решение

- OCR: Tesseract 5 (`rus+eng`), поставляется в бандле приложения.
- Классификация типа документа: TF-IDF + логистическая регрессия, инференс на Dart.
- Извлечение полей: regex, словари, эвристики по координатам слов, шаблоны бланков.
- Таблицы: восстановление по bounding boxes + OpenCV.
- Опционально: rubert-tiny2 через ONNX Runtime Mobile для ФИО и организаций.
- Сервер не выполняет OCR, классификацию и извлечение. Он хранит оригиналы, JSON и превью, обеспечивает синхронизацию.
- Генеративные модели запрещены. Если поле не найдено — `null`.

## Последствия

- Полная офлайн-работа распознавания, сильная приватность.
- Качество на плохих фото ниже, чем у облачных OCR: нужны предобработка, шаблоны, ручная правка.
- Размер приложения растёт: бюджет ≤ 120 МБ AAB.
- Нужна матрица устройств и бюджеты производительности (≤ 8 с/страница, ≤ 300 МБ RAM).
- Обновление моделей — через релиз приложения (позже — с нашего сервера).
