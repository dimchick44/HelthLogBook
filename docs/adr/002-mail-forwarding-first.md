# ADR-002. Почта: пересылка вместо OAuth в MVP

## Контекст

Чтение почты через Gmail API — restricted scope: требуется верификация Google и ежегодная security-оценка (CASA). Microsoft Graph и IMAP требуют отдельных интеграций и хранения секретов. Это блокирует ранний запуск.

## Решение

В MVP пользователь создаёт правило пересылки в своём ящике на уникальный адрес вида `u-<token>@in.<домен>`.

- Сервер принимает письмо, разбирает MIME и сохраняет вложения в `inbox_items`.
- Устройство забирает вложение по API, распознаёт локально и присылает результат.
- Сервер не отправляет и не удаляет письма, доступ только к пересланным сообщениям.
- IMAP — следующий этап (S-приоритет). Gmail/Graph OAuth — после верификации, вне MVP.

## Последствия

- Нет OAuth-верификации и CASA на старте.
- Работает с любым ящиком: Gmail, Outlook, Яндекс, Mail.ru.
- Пользователь должен один раз настроить пересылку — это трение в onboarding.
- Нет доступа к истории ящика: только новые пересланные письма.
- Появляется статус «ожидает обработки на устройстве», если телефон офлайн.
